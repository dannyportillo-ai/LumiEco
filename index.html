Iluminación Inteligente y Sostenible

LumiEco es un sistema automatizado que utiliza la plataforma Arduino para detectar presencia humana, encendiendo la luz solo cuando es necesaria. Un paso sencillo para reducir drásticamente el desperdicio energético en entornos residenciales o de taller.

El Desafío del Desperdicio Energético

Las luces olvidadas representan un porcentaje masivo del consumo fantasma en hogares y oficinas.Un sistema que no responde a la presencia humana es ineficiente por diseño.

Muchas veces las luces permanecen encendidas incluso cuando no hay personas en el lugar, generando un gasto energético que podría evitarse.

Nuestra Solución: LumiEco

LumiEco busca solucionar este problema mediante un sistema inteligente capaz de detectar la presencia humana y controlar automáticamente la iluminación.

Paso 1

Detencion

El sensor PIR detecta movimiento en el área de cobertura.

Paso 2

Procesamiento

Arduino Uno recibe la señal y ejecuta la lógica programada.

Paso 3

Accion

El LED se enciende mientras hay presencia. Se apaga al no detectar movimiento.

Componentes

Elementos utilizados para construir el prototipo LumiEco.

Anatomia de LumiEco

Arduino Uno

El cerebro del sistema. Microcontrolador que procesa las entradas del sensor y gestiona el estado de salida.

VOLTAJE: 5V

Sensor PIR

Sensor infrarrojo pasivo para detectar movimiento humano en el entorno cercano.

ESTADO: SENSING

LED

Fuente de luz que responde a la lógica del Arduino. Simula la lámpara final de la habitación.

SALIDA: ACTIVA

Protoboard

Placa de pruebas para conectar de forma segura y sin soldadura los componentes electrónicos.

Estructura de Madera

Soporte físico sostenible fabricado en madera o cartón reciclado, alojando el montaje de forma ordenada.
